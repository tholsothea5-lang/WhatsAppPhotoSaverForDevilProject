Save WhatsApp photos
with their captions.

A bookmarklet for WhatsApp Web. Pick a chat and a date range, and get one ZIP organised as chat → date → caption → photos. No account, no server, no upload.

Install the bookmarklet

⬇ WhatsApp Photo Saver
Loading the bookmarklet…
Drag the green button onto your bookmarks bar, then open web.whatsapp.com and click it there. Not on this page.
  1. Show your bookmarks bar — press Ctrl + Shift + B (⌘ + Shift + B on Mac).
  2. Drag the green button up to that bar. It becomes a bookmark named “WhatsApp Photo Saver”.
  3. Open WhatsApp Web, sign in if asked, then click the bookmark. A small panel appears in the corner.
  4. Pick a chat and range, press Scan, then Download ZIP. Your browser saves the archive.

What you get

        └── No caption
            └── Rabin_22-10-2026_183001_ab12cd.jpg

One folder per chat, then per day, then per caption. Album photos share the album’s single caption, and photos without one go to No caption. Filenames are sender_date_time_hash.ext, so nothing is overwritten when you re-download.

Photos without captions still work

Captions are read from the message itself, including album captions that sit on a sibling photo or video.

Videos are opt-in

Tick “Include videos” to pull MP4s too. They use the same folder and naming rules.

Re-downloads don’t duplicate

Each filename carries a short hash of the chat and message id, so the same photo always gets the same name.

Chat list respects your contacts

Groups and direct chats are named the way WhatsApp shows them, with a numeric suffix only when two names collide.

Questions

Is this safe? Where does my data go?

Nowhere. The bookmarklet is a plain script that runs inside the WhatsApp Web tab you already have open. It reads WhatsApp’s own local storage in your browser, downloads each photo straight from WhatsApp’s CDN, decrypts it in memory, and builds the ZIP locally. There is no server, no account, no analytics, and no upload. This page is static files only.

Do I have to give it my password or scan a QR code again?

No. It uses the session your browser already has. If WhatsApp Web is logged in, the bookmarklet is too. It never sees your password and never creates a linked device.

Why are some photos missing or marked failed?

WhatsApp Web only keeps a limited slice of history on your device, and old media expires on WhatsApp’s servers. Anything already expired returns HTTP 404/410 and cannot be recovered by any tool. The panel lists those failures and still gives you a ZIP with everything that worked.

Nothing happens when I click the bookmark.

Make sure you are on web.whatsapp.com with the chat list visible, not on this page. Then click the bookmark again. If you use Firefox, paste the code into a bookmark’s URL field instead of dragging — Chrome, Edge, and Brave handle dragging best.

How large a range can I export?

The ZIP is assembled in memory, so a few hundred photos is comfortable. For very large exports, run the download once per month, or use the local Python version from the repository, which writes straight to disk and skips files you already have.

Does it work on my phone or tablet?

No. Mobile browsers do not support bookmarklets on WhatsApp Web, and WhatsApp Web itself is a desktop experience. Use a desktop browser.

Why does it need to call WhatsApp internals?

WhatsApp stores captions in an encrypted field that is only readable through the page’s own message models. The bookmarklet asks those already-loaded models for the caption text. If a future WhatsApp update changes that, captions fall back to No caption and the photos still download normally.

Before you use it

Use it on your own account. This automates your own WhatsApp Web session, which is outside WhatsApp’s terms of service — that is your call and your risk, and a future WhatsApp update may break it. It does not bypass encryption, read other people’s accounts, or send anything anywhere. Please also respect the privacy of the people in your chats before you share an export.
